# Adaptive UI Modality Engine (Lab 3)

A single-file HTML app that adapts its interface to the user's input modality (mouse, touch, pen, keyboard), and lets the user control and approve adaptations.

## Features
- Auto-detects input modality using Pointer Events and keyboard Tab
- Adapts button size, font size, spacing and focus ring per modality
- User preferences: theme, accent colour, density, text size, corner radius, high contrast, reduce motion
- Suggestions the user can accept or dismiss, with acceptance stats
- Task board demo, voice commands, activity log, JSON export

## How to run
Open `adaptiveUI.html` in any modern browser. No install needed.
